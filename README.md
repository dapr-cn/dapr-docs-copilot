# Dapr Docs Copilot Console

基于 `Vite + React + TanStack Router + TanStack Query + TanStack Table + shadcn/ui` 的单一站点管理端脚手架。

## 已包含

- 单页管理端骨架与响应式侧边导航
- `TanStack Router` 路由分区：总览 / 站点 / Copilot / 设置
- `TanStack Query` 本地 mock 数据查询层
- `TanStack Table` 站点矩阵管理视图
- `shadcn/ui` 风格基础控件：Button / Card / Badge / Input / Tabs / Table / Switch / Avatar 等
- 可继续扩展的 AI 工作台与设置页占位

## 启动

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```
